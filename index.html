Choose Your Program Level

Both curriculums are grounded in the Micro:bit Educational Foundation's foundational projects. Select the program tailored for your students' age group and computer experience.

Plan A • Ages 8–11

Elementary–Middle School

Designed for beginner computer users

Assumes no prior typing or computer experience. Starts with basic mouse and browser skills before progressing one project per week through interactive badges, animations, step counters, and a final review showcase.

  • Session length: 45–60 minutes
  • Pace: 1 foundational project per week
  • Focus: Core concepts (loops, variables, sensors)
  • No physical hardware required (on-screen simulator works)

Plan B • Ages 11–16

Middle–High School

Faster paced with real text-based code

Built for students comfortable with computers. Moves at double-pace through foundational projects, then expands into functions, nested logic, short-range radio communication between boards, and real JavaScript/Python code.

  • Session length: 60–75 minutes
  • Pace: 2 projects per week early on, then advanced extensions
  • Focus: Functions, radio networking, and text-based editing
  • Culminates in an original, student-planned final project
